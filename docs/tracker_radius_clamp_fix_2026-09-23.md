# 跟踪中断与半径约束修复（2026-09-23）

## 结论

用户手动测试后反馈云台无异常。本轮定位到一个确定的软件几何缺陷：EKF 半径超限时，
原实现只截断半径，不调整中心，导致重建出来的装甲板位置跳变，进而被自身的匹配门限拒绝。
已修复，并通过同一份输入的离线前后对比验证。用户随后断开机器人，后续工作全部离线完成。

本次不修改 YOLO 权重、曝光、匹配门限、确认帧数、Q/R 参数或下位机代码；没有重新启动
自动跟随或进行修复后的电机运动测试。本修复与此前的无效零角度误转发修复是两个独立问题。

## 修复原理

当前观测装甲板位置由中心和半径共同确定：

```text
xa = xc - r * cos(yaw)
ya = yc - r * sin(yaw)
```

将 r 约束为 r_new 时，同步更新：

```text
xc_new = xc + (r_new - r) * cos(yaw)
yc_new = yc + (r_new - r) * sin(yaw)
```

这样约束前后的 xa、ya 保持一致。仍使用九维 EKF，沿用原半径上下限和协方差处理，
没有新增自适应调参。中心与半径在只看到单块装甲板时的可观测性仍有限，
此修复不等于完整解决车辆中心估计或完成实机 Q/R 调参。

   之前自动跟随时的姿态跳变和反馈积压仍未据此排除。
