# 自瞄计算、弹道、云台与通信学习路线

更新日期：2026-08-30

## 1. 学习目标

这组讲义只学习下面这条链路：

```text
装甲板像素点
  -> PnP 三维坐标
  -> 坐标变换
  -> 目标状态估计
  -> 几何瞄准
  -> 弹道与运动预测
  -> 云台可执行轨迹
  -> 安全命令
  -> 下位机通信
```

不在这组讲义中重新讨论模型训练、gray140 数据采集、相机帧率诊断或主机选型。

## 2. 预计时长

| 学习方式 | 预计总时长 |
|---|---:|
| 只理解核心概念 | 12～16 小时 |
| 逐段读源码、手算并答题 | 18～25 小时 |
| 每天学习 1～1.5 小时 | 约 2～3 周 |

对于第一次接触机器人坐标、弹道和下位机通信的人，建议采用第二种方式。

## 4. 学习方法

每课按同一顺序进行：

1. 先建立物理直觉，明确输入、输出和单位。
2. 再读真实源码，确认程序到底实现了什么。
3. 完成一个带数字的例子。
4. 在聊天框回答课末检查题。
5. 根据回答纠正理解，再进入下一批课程。

聊天框答题格式：

```text
第1题：...
第2题：...
第3题：...
```

讲义中只放问题，不预先写出答案。

## 5. 三种证据等级

学习时必须区分以下说法：

| 标记 | 含义 |
|---|---|
| 源码已实现 | 能在仓库中指出实际执行代码 |
| 可以离线验证 | 能通过公式、单元测试或录制数据验证 |
| 当前机器人已实机验收 | 已使用当前机器人的真实参数、协议和硬件测试 |

参考项目中存在某段代码，只能证明“参考项目源码已实现”。它不能证明当前机器人已经完成实机验收。

## 6. 参考边界

主要参考项目：

```text

```
