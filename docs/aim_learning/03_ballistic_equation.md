## 3. 输入、输出和单位

`trajectory.hpp` 对输入输出作了明确说明：

| 变量 | 物理含义 | 单位 |
|---|---|---|
| `v0` | 弹丸离开枪口时的速度大小 | m/s |
| `d` | 目标水平距离 | m |
| `h` | 目标相对枪口的竖直高度 | m |
| `pitch` | 所需发射仰角，抬头为正 | rad |
| `fly_time` | 弹丸飞到目标水平位置所需时间 | s |
| `unsolvable` | 当前输入下是否没有实数角度解 | bool |

注意 `d` 是水平距离，不是三维斜距。参考 `Aimer` 中的计算：

```cpp
double d = std::sqrt(xyz.x() * xyz.x() + xyz.y() * xyz.y());
tools::Trajectory trajectory(bullet_speed, d, xyz.z());
```

## 4. 模型作了哪些假设

当前 `Trajectory` 使用理想抛体模型：

```text
重力恒定
忽略空气阻力
弹丸离开枪口后没有额外动力
地面参考系近似惯性系
发射瞬间初速度精确等于 v0
目标位置在这一小节中先视为已知
```

源码使用：

```cpp
constexpr double g = 9.7833;
```

单位是 `m/s^2`。

这个模型适合建立算法核心和离线单元测试，但不代表无需实弹标定。真实弹丸还会受到空气阻力、弹速波动、枪管安装误差等影响。

## 5. 第一步：分解初速度

设发射仰角为 `pitch`，简写为 `theta`。

初速度可以分解为：

```text
水平速度：v0 * cos(theta)
竖直速度：v0 * sin(theta)
```

水平距离随时间变化：

```text
d = v0 * cos(theta) * t
```

因此飞行时间为：

```text
t = d / (v0 * cos(theta))
```

这正是源码 `trajectory.cpp:26-27` 计算两条弹道飞行时间的方法。

## 6. 第二步：写出竖直运动

竖直方向初速度向上，重力加速度向下：

```text
h = v0 * sin(theta) * t - 1/2 * g * t^2
```

把水平运动得到的时间代入竖直运动方程：

```text
h = d * tan(theta) - g*d^2 / (2*v0^2*cos(theta)^2)
```

这就是交接文档中给出的弹道方程。

## 7. 第三步：变成一元二次方程

直接求 `theta` 不方便。令：

```text
u = tan(theta)
```

利用恒等式：

```text
1 / cos(theta)^2 = 1 + tan(theta)^2 = 1 + u^2
```

代入后：

```text
h = d*u - g*d^2/(2*v0^2) * (1 + u^2)
```

定义：

```text
a = g*d^2 / (2*v0^2)
```

移项得到：

```text
a*u^2 - d*u + (a+h) = 0
```

与标准二次方程 `a*u^2 + b*u + c = 0` 对比可得：

```text
a = g*d^2 / (2*v0^2)
b = -d
c = a + h
```

这与 `trajectory.cpp:11-14` 完全对应：

```cpp
auto a = g * d * d / (2 * v0 * v0);
auto b = -d;
auto c = a + h;
auto delta = b * b - 4 * a * c;
```

## 8. 判别式为什么代表“能不能打到”

一元二次方程的判别式是：

```text
delta = b^2 - 4*a*c
```

| 判别式 | 数学结果 | 物理含义 |
|---|---|---|
| `delta > 0` | 两个实数根 | 通常有高抛和低抛两条角度 |
| `delta = 0` | 一个重复实根 | 恰好达到射程边界 |
| `delta < 0` | 没有实数根 | 当前弹速无法到达该位置 |

源码中的失效处理是：

```cpp
if (delta < 0) {
  unsolvable = true;
  return;
}
```

`Aimer` 收到 `unsolvable=true` 后会返回无效控制命令，而不是继续使用一个虚假的角度。

## 9. 为什么会有高抛和低抛两条解

当 `delta > 0` 时：

```text
u1 = (-b + sqrt(delta)) / (2*a)
u2 = (-b - sqrt(delta)) / (2*a)
```

再通过：

```text
pitch1 = atan(u1)
pitch2 = atan(u2)
```

得到两个角度。

直觉上：

```text
低抛：角度较小，路径较平，飞行时间短
高抛：角度接近竖直，路径很高，飞行时间长
```

源码分别计算两条轨迹的飞行时间，然后选择更短的一条：

```cpp
pitch = (t_1 < t_2) ? pitch_1 : pitch_2;
fly_time = (t_1 < t_2) ? t_1 : t_2;
```

对于自瞄，低抛通常更合理，因为飞行时间短意味着目标运动造成的提前量更小，也更符合云台和场地的实际使用方式。

## 10. 完整数值例子

假设：

```text
弹速 v0 = 23.0 m/s
水平距离 d = 4.0 m
目标高度 h = 0.10 m
重力 g = 9.7833 m/s^2
```

### 10.1 计算二次方程系数

```text
a = g*d^2/(2*v0^2)
  = 9.7833*4^2/(2*23^2)
  ≈ 0.147952 m

b = -4.0 m

c = a+h
  ≈ 0.247952 m
```

这里把 `u=tan(theta)` 看作无量纲量，则 `a`、`b`、`c` 都带长度单位，三项可以相加。

### 10.2 计算判别式

```text
delta = b^2 - 4*a*c
      ≈ 15.853261 m^2
```

`delta > 0`，因此存在两条实数弹道。

### 10.3 两条弹道

计算结果为：

| 弹道 | `tan(pitch)` | pitch | fly_time |
|---|---:|---:|---:|
| 高抛 | 26.9737 | 87.8768° | 4.6943 s |
| 低抛 | 0.06213 | 3.5553° | 0.17425 s |

源码选择低抛解：

```text
pitch ≈ +3.56°
fly_time ≈ 0.174 s
```

如果完全忽略重力，水平飞行时间粗略为：

```text
4/23 ≈ 0.174 s
```

与低抛的精确时间很接近；但枪口必须向上补偿约 `3.56°`，否则弹丸会落到目标下方。

## 11. 一个无解例子

仍取 `v0=23 m/s`，若目标与枪口等高且理想水平距离达到 `60 m`，当前无阻力模型的判别式会小于零。

物理含义是：即使选择最有利的发射角，这个初速度也不足以让弹丸在下落前到达目标位置。

真实弹丸存在空气阻力，实际有效范围通常比这个理想模型更受限制。这里的例子只用于理解判别式。

## 12. 弹道 pitch 与最终命令符号

`Trajectory::pitch` 明确规定“抬头为正”。对于前面的例子，它返回正的 `3.56°`。

但 `Aimer` 最终执行：

```cpp
double pitch = -(current_traj.pitch + pitch_offset_);
```

这是参考项目下位机命令约定造成的符号转换，不是弹道方程把重力方向写反。阅读时应分开：

```text
物理弹道层：抬头为正
通信命令层：按下位机协议转换符号
```

## 13. 源码已经实现与尚未处理的边界

源码已经实现：

```text
无阻力弹道方程
判别式无解检测
高低两条弹道求解
选择飞行时间更短的弹道
输出 pitch 和 fly_time
```

当前 `Trajectory` 本身没有显式处理：

```text
v0 <= 0 的输入校验
d = 0 的特殊情况
空气阻力
弹速测量噪声
枪管真实出口位置
弹丸批次差异
实弹落点标定
```

另外，参考 `Aimer` 在弹速小于 `14 m/s` 时直接回退到 `23 m/s`。这是原机器人的策略，不允许直接复制到当前项目。

## 14. 本课核心结论

```text
静止目标也需要补偿重力下坠
水平运动给出飞行时间，竖直运动给出高度关系
令 u=tan(pitch) 后可化为一元二次方程
判别式小于零表示当前弹速下没有可达角度
两个实根通常对应高抛和低抛
参考源码选择飞行时间更短的低抛解
弹道 pitch 的物理符号和下位机命令符号必须分层理解
```
